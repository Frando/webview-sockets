Native UDP demo

Sends and receives real UDP datagrams from this page through window.webviewSockets.udp, which a webview-sockets host app provides (add ?api=udpsocket to use the Direct Sockets UDPSocket instead). Run udp-echo listen --port 4433 on another machine and send to it.

    Automation
    
    ?peer=ip:port&send=text&expect=text sends and waits for the
    reply; ?connect=host:port&send=text&expect=text[&dnsQueryType=ipv4]
    does the same with a connected socket (host may be a name); ?api=udpsocket
    uses UDPSocket for everything; ?bench=ip:port[&n=2000&count=20000&window=64] runs a
    1200-byte ping-pong and a windowed throughput test against an echo server;
    ?echo=1 starts in echo mode. Results are logged as
    UDP-DEMO PASS|FAIL ... and set as the page title.
