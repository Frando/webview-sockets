Native UDP demo (Rust)

Sends and receives real UDP datagrams from Rust compiled to wasm. The Rust code uses wasm_native_udp::UdpSocket, which talks to the iroh-link browser. Run udp-echo listen --port 4433 on another machine and send to it.
