webview-sockets self test

Checks webviewSockets.udp and the UDPSocket compatibility layer (Direct Sockets API) on loopback: bound and connected mode, GSO, GRO, host names, errors and close. Optional: ?peer=ip:port&send=text&expect=text also sends to an external echo server. ?denied=1 only checks that opening fails with NotAllowedError (run the test-host without --auto-grant). Result in the title: UDP-TEST PASS|FAIL detail.
