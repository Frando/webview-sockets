UDPSocket self test

Checks the webview-sockets UDPSocket (Direct Sockets API) on loopback: bound and connected mode, GSO, host names, errors and close. Optional: ?peer=ip:port&send=text&expect=text also sends to an external echo server. ?denied=1 only checks that opening fails with NotAllowedError (run the test-host without --auto-grant). Result in the title: UDP-TEST PASS|FAIL detail.
